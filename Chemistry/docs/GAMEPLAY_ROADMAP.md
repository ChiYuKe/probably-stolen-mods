开局从第一个夜晚开始：玩家打烊后去垃圾堆翻找废弃物品，把捡到的未知废料带回地下实验室，检测成分、亲手提炼，再把成品交给收购者。玩家先因好奇开始拆解废料，随后才通过委托获得明确目标。第一段流程以交付一份回收铁为终点，之后逐步开放批量生产和长期供货。

## 开局流程：第一个夜晚捡到一块废料

首晚不先弹出一笔化学订单。玩家先在夜间前往垃圾堆，靠翻到的废弃物品发现玩法；回店后收到沈老师留下的地下室线索，第二次夜间行动进入实验室。完成首次检测并看到含铁结果后，老锈再提出回收铁的委托。这样委托能解释为什么要继续做，而不是替玩家讲解尚未体验的系统。

| 顺序 | 玩家行动 | 教学反馈与兜底 |
| --- | --- | --- |
| 1. 夜间翻找 | 当铺首日结束后，在夜间地点选择垃圾堆，执行一次翻找，获得未知金属碎片或普通废金属 | 首次翻找保证至少一件可送检样品。其他掉落仍按现有垃圾场掉落表随机生成。失败或背包满时提示原因并保留重试机会 |
| 2. 带回当铺 | 玩家在夜间行动结束后，把样品存入库存或实验室储物格 | 物品提示说明「成分未知，可用光谱仪分析」，不直接给出元素 |
| 3. 找到地下室 | 旧笔记或店内线索指向当铺地下室，开放地下实验室入口 | 入口开放与剧情步骤存档。错过线索或离开地点后仍能从委托/实验台记录找到入口 |
| 4. 首次检测 | 用光谱仪扫描样品，查看批次、含量和杂质 | 检测完成后才揭示成分，并指出下一步可回收铁。若玩家先收集其他样品，照样可以先分析 |
| 5. 接到回收委托 | 老锈在此后出现，提出收购一份废料里回收的铁 | 委托指向已看过的报告和对应工艺，避免前后流程脱节 |

## 第一笔委托：老锈收一份回收铁

| 步骤 | 玩家做什么 | 界面反馈与完成条件 |
| --- | --- | --- |
| 1. 准备原料 | 使用首晚翻到的未知金属碎片或普通废金属；若样品不含铁，再去垃圾堆翻找 | 委托记录显示可用批次和建议目标，不会要求已证明无法回收的成分 |
| 2. 查看检测报告 | 在地下室用光谱仪检测含铁样品 | 报告列出批次、成分和目标铁。优先安排批次 01 作为保底样品，其铁含量为 72%。其他样品报告也保留 |
| 3. 比较成本 | 在报告选铁，查看本批所需废料、试剂、库存和报酬。低品位批次可以先收起来 | 投料数直接调用提炼台现有用量计算。不同批次使用各自对应的工艺。教程默认引导普通废金属或批次 01 的盐酸路线 |
| 4. 制备试剂 | 从反应台打开制酸装置，按游戏配方拖入原料、器皿和空瓶，启动，取走成品 | 工位列出具体缺件和取得地点。设备成功产出对应试剂后勾选教学步骤，打开界面或点启动都不算完成 |
| 5. 回收铁 | 回到提炼台投料，处理浸出液、用漏斗过滤，再将滤液还原，取出铁 | 每个中间品提示下一工位。首次教学以实际产出铁记进度。玩家在中途离开后，重新打开委托能找到已有物料 |
| 6. 回店交货 | 带铁回当铺，在订单交付槽放入一份铁。确认页显示将交出的数量和到手信用点 | 订单要求已亲手回收过铁且交付槽有一份铁。成功后扣一份、付一次钱、留下结算记录。剩余铁可摆柜出售 |

**避免开局卡死。** 首单接取时按路线核查光谱仪、制酸器具、空瓶、过滤漏斗、废料数量及制酸配方的全部上游原料。给缺工具的存档提供可重复使用的借用工位，样品和缺失的消耗品可按一批用量领取。补领通过交回中间品或按成本补货处理，避免重复接单套取物资。关闭开局补给也应有可用路径。首单无期限，经营损失只影响耗时和利润。

**处理提前生产。** 已检测样品和已有中间品可以直接用于对应工序。首单教学分别记录看过报告、成功制剂和实际回收，允许先做后看。普通补货单只认约定品种和实交数量，玩家可以提前备货。旧档已有的库存可继续使用，缺少历史记录的操作可重做一次。

## 中后期：让订单决定设备怎么用

| 阶段 | 代表订单与玩家选择 | 结算或解锁 |
| --- | --- | --- |
| 前期手动 | 首单后开放铜回收单。比较两份烧蚀电路板报告，选含铜较高的一批节省原料，或留给更有价值的目标。缺试剂时转入手工作坊 | 增加一个可重复接取的回收委托。报价同时列出交付价和当铺参考售价，让玩家决定是否留货 |
| 中期批量 | 开放 2–4 瓶的试剂补货单。玩家可沿用手工工位，也可按现有施工要求投资设备组，自行决定排几份、何时转运、预留多少空瓶 | 每批实际入库才累计数量。订单单价与手工路线使用同一规则，设备的收益来自少操作及更快周转 |
| 后期工业 | DSC-07 连续采购两批货。试剂单走硝酸联机线，固体单按独立工业车间的实际产物派发。玩家设置库存上限、补动力、清理出料仓，选择先交哪单 | 首个长期合同结清后开放同类复购。仅对已具备原料渠道且设备已可建造的路线派单，尊重工业车间现有第 12 天门槛 |

首轮平衡记录每单消耗的废料、试剂、瓶、动力、游戏刻、手动转运次数和净收入。首单以教会操作为主。批量线至少减少每份成品的手动操作次数；若升级后的同单净收入反而下降，应让订单预览明确展示成本，调整报酬或扩产成本后再开放连续合同。

## 开发顺序与验收

| 里程碑 | 实施内容及依赖 | 通过条件 |
| --- | --- | --- |
| M1 原料可达 | 从首单的铁和制酸耗材逆推到垃圾场、商店或借用工位。对全部元素列出样品、分离或其他可获得渠道。先补关键缺口，再从普通垃圾场移除元素表挂载。稀有原料可设计为采购或专项样品 | 普通与新鲜垃圾场的有效掉落路径均无单质直掉；关闭开局补给的新档，能够不用调试包备齐首单；移除掉落后仍有渠道取得原先依赖它的配方原料 |
| M2 首单交付 | 依赖 M1。接入来访 NPC、报告、制酸出料、提炼出料及交付台。沿用原版储物槽、机器双击交互和地下室交通入口，在现有流程指南显示当前目标 | 用普通废金属完成一次首单。再用批次 01 完成同单。错误物品、仓满、余额或库存变化、重复确认都不造成吞料或双倍报酬 |
| M3 批量补货 | 依赖 M2。复用委托与结算逻辑，加入铜回收和多瓶交付；用现有设备施工条件提示升级。单据明确瓶型、每瓶装量或总量，按订单约定校验 | 同一补货单手动、批处理均可交付；半瓶、错液、空瓶不能冒充满瓶；比较两条路线的操作数与净收入 |
| M4 连续供货 | 依赖 M3。把库存、动力、产物上限接入合同提示；停线时显示具体原因和恢复动作。按现有生产线的时钟和离场规则估算到货 | 分别用试剂线和固体线履约；模拟断料、满仓和离场读档，补齐后接着生产；两批分别交付，合同只结清一次 |

**存档与交互约束。** 为每次接单保存独立订单编号、目标、已完成步骤、交货量和结算状态，沿用模组存档机制。章节奖励与订单报酬分别记账。进度由产出成功、交货成功等业务事件推进，界面只展示状态。结算时同时校验并更新库存、订单、信用点，中途失败恢复到可重试状态。读档或切换存档后按该档恢复。每个里程碑至少覆盖新档、旧档、加工中读档、交付前后读档及重复点击。

**开局流程完成标准。** 新档玩家能从首日营业进入第一个夜晚，在垃圾堆翻到可检测的废料，带回当铺并找到地下室；随后能看懂检测报告、完成制剂和提炼，最后把回收铁交给老锈。随机掉落不能让教学链断掉，重复翻找也不能重复领取首晚保底样品。达到这一点后再扩展订单数量与公司经营系统。

## 落地后的实现备注

- **存档键**：`order_active` / `order_done` / `order_history` / `order_seq` / `order_borrowed`，
  加上全局履历 `order_seen` / `order_made` / `order_recovered` / `order_produced` 和首翻保底标记
  `loot_first_sample`，全部走 `ModHelper.SetModData`，随存档保存；损坏数据按空处理。
- **开局顺序**：垃圾场首翻不是样品或样品不含铁时，临时替换为含铁的批次 01。
  只有含铁样品进入玩家库存后才写入 `loot_first_sample`；库存放不下或物品未拾取时保底机会保留。
  首单 `RequiresAnalysis = true`，必须看过含铁样品的报告才会出现；任意不含铁报告不会解锁老锈。
  这样「翻垃圾 → 检测含铁样品 → 老锈出现」的顺序不会跳步，失去掉落也不会耗掉保底。
- **先做后看**：`report`（看过报告）、`reagent`（制出试剂）、`recover`（亲手回收）、`produce`（累计产量）
  四个步骤都读全局履历。接单之前扫过、做过的事在接单那一刻补记，所以「先扫废料再点接单」不会被判成没做过。
- **进度入口**：委托记录同时挂在 F6 实验台的「委托」页和地下实验室面板的「委托」页，F9 也有独立入口，
  所以错过当日 NPC 来访不会丢单。
- **结算顺序**：先校验教学步骤 → 再校验店里数量与满瓶数 → 先扣库存 → 再发信用点。
  扣库存或发钱任一步失败都会把已扣的材料放回店里，订单保持可重试；成功后才清空进行中的委托，
  因此重复点击不会双倍发钱。
- **分批交付**：`OrderTemplate.Lots > 1` 的长期合同每次只扣一批并记 `DeliveredLots`，
  交满批数才付一次钱（DSC-07 两张合同都是 2 批）。
- **满瓶校验**：`OrderRequirement.Bottles > 0` 时还要满足指定尺寸、瓶数和总液量；盐酸补货固定为 3 个满小瓶（每瓶 4 单位）。
  半瓶、空瓶、破损瓶、中大瓶和别的液体都不算；结算完整扣除匹配的三只小瓶，不从其他瓶型或半瓶补差。
- **产量单位**：委托按 `MachineBatch` 实际提交到库存的 `Product.Units` 累计；`TryCommitBottled` 当前每批写入 1 单位。
  瓶型容量只是上限，不能把大瓶容量当成已生产的液量。
- **借用工位**：只有整批都放进仓库才消耗那一次机会（`order_borrowed`）；仓库满时领到一部分，
  清出空间还能再领剩下的 —— 没领到的部分下次 `Audit` 仍会列出来，不会重复发放。
- **首单保底**：接单时手上完全没有含目标元素的废料，就直接给一批 01 号样品，
  避免第一次翻垃圾空手而归。不占用借用工位的机会，也不会重复发放（`HasAnyScrapFor` 先查再给）。
- **原料采购**：垃圾场不再直掉单质后，`OrderPurchase` 给每种元素一条明码标价的采购渠道
  （价格 = 元素价值 × 4，下限 24），结清首单后解锁。翻垃圾仍然更划算，采购只作兜底。
- **工业线接入**：硝酸联机线和工业车间出料成功时按实际入库单位数调用
  `OrderService.OnCompoundProduced(def, units)`，长期合同的「生产」步骤按累计产量推进，
  不需要玩家手动回店确认。
- **仍未做**：合同的界面提示还没有把「断料 / 满仓 / 缺动力」的具体原因和恢复动作搬进委托页，
  目前仍看生产线自己的状态行；平衡数据（每单废料、试剂、瓶、动力、游戏刻、净收入）也还没记录。
