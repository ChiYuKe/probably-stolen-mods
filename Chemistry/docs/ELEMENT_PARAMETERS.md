# Chemistry 元素参数框架

118 种元素都进入周期表。其中 **81 种走常规回收**，分 **17 种前期、39 种中期、25 种后期**。其余 **17 种通过研究委托解锁，20 种通过研究档案解锁**。垃圾场提供含元素的样品，玩家用光谱仪确认组成，再把选中的成分交给对应设备处理。

逐元素配置见 [element_gameplay.csv](../data/element_gameplay.csv)。这份表是待接入的玩法参数。当前 `LootIntegration` 仍把 118 种单质直接加入垃圾场掉落，`LabWorkflow` 也沿用该来源提示。

## 数据与归属

| 数据 | 归属 | 用法 |
| --- | --- | --- |
| 原子序数、符号、中英文名、分类、周期和族 | `data/elements.csv` | 按现有流程由 `gen_elements.py` 生成 `ElementTable.cs`。镧系和锕系的 `group=0` 供当前周期表布局使用。 |
| 相对原子质量、熔点、沸点、密度及其单位、电负性、电子排布、发现与命名资料 | `data/elements.csv` | 周期表和物性详情读取。数值缺失时显示「未知」。密度要绑定相态和参考条件，留有压力或同素异形体差异的数值只作带条件的图鉴资料。 |
| 获取阶段、样品来源、回收路线、展示形态、操作权限、交易权限 | `data/element_gameplay.csv` | 用 `symbol` 与元素目录连接。CSV 里的身份、质量数值、目录基础价和物品键是供筛选的现有数据快照，接入时从原目录和现有方法取得。 |
| 每种样品的克数、成分比例、掉落权重、批次和可处理的目标 | `SampleTable` 和各设备路线 | 写到具体样品批次。元素表只给出默认样品族和回收方向，同一种元素可来自多个批次。 |
| 设备耗材、耗时、批量上限、产物接收槽 | 对应机器配置 | 由设备路线决定。阶段解锁后，仍须有有效的投料、设备与产物空间。 |
| 液体颜色、瓶型、液面遮罩、气瓶与贴图占格 | `MaterialAppearance`、`MaterialItemArt`、`ReagentBottle` | 沿用物品与容器渲染入口，贴图名称由 `el_<symbol 小写>` 得到。物品 ID 为 `chem_el_<symbol 小写>`。 |

### 逐元素字段

| 字段 | 值域和规则 |
| --- | --- |
| `number`、`symbol`、`name_zh`、`category` | 与元素目录一致。符号区分大小写，`Co` 表示钴。 |
| `catalog_mass`、`mass_kind` | 沿用目录数值，`standard_atomic_weight` 表示标准原子量代表值，`isotope_mass_number` 表示参考核素的质量数，图鉴用方括号显示。放射性与是否有标准原子量分别判断，钍、镤、铀在表中仍用标准原子量。 |
| `phase_20c`、`phase_basis` | 相态参考条件为 20 °C、约 1 个大气压。相态为 `solid / liquid / gas / unknown`。依据为 `catalog_reference / predicted / unknown`，分别表示沿用项目目录、文献预测、缺少可用的常温相态。图鉴给预测值加上「预测」，质地和容器由 `display_form` 决定。 |
| `stage` | `bench / batch / industrial / archive`，对应下表的获取进度。 |
| `sample_family`、`route` | 默认来源族与处理路线。实际批次由 `SampleTable` 引用，机器面板按该批次的可回收目标过滤。 |
| `display_form` | `metal_powder / granules / liquid_bottle / gas_vial / sealed_specimen / archive_record`。 |
| `handling` | `standard` 走标准槽位，`controlled` 需要匹配的封装槽，`restricted` 只允许对应路线的封闭机台或接收槽，`research` 只在研究委托或档案内处理。这一列控制游戏交互权限。 |
| `trade_policy` | `market` 可按正常物品流程交易，`contract_only` 通过一次性委托结算，`catalog_only` 只登记研究记录。 |
| `catalog_value` | `ElementDef.Value` 的目录参考值。库存统一按 1 g/单位，实际单价按参考值除以相对原子质量并取整，至少为 1；采购加价另行计算。 |
| `item_id`、`sprite_key` | 现有存档键和美术键。档案条目的物品 ID 用于识别旧库存及目录项，新解锁直接登记元素符号。 |

### 阶段与机器

以下批量是首轮平衡起点，每批按可结算的**单质份数**计，上限也受投料和产物槽限制。

| 阶段 | 元素数 | 解锁条件 | 单批上限与交互 |
| --- | ---: | --- | --- |
| `bench` 前期实验台 | 17 | 到访地下实验室并完成首次光谱检测 | 1 份。手动选目标、放入耗材和接收容器、取出成果。 |
| `batch` 中期批量 | 39 | 完成一次前期回收并安装批处理模块 | 4 份。同批次、同目标批量处理，玩家负责补料和收取。前期路线也可批量运行。 |
| `industrial` 后期工业 | 25 | 完成一次批量回收并装配厂房与对应设备线 | 16 份。同一套成分和耗材规则，生产线自动搬运与收集。产物槽满时暂停启动下一批。 |
| `archive` 研究收藏 | 37 | 开启研究档案；具体条目由委托交付或研究报告解锁 | 17 个委托条目可展示封装标本。20 个档案条目以记录解锁。 |

| `route` | 来源和接入方式 |
| --- | --- |
| `metal_recovery` | 金属废料、矿渣、电路板、电池、合金、磁体和催化部件。沿用光谱鉴定 → 提炼反应台前处理 → 滤液 → 还原槽出单质；游戏耗材由具体批次指定。 |
| `solid_separation` | 矿渣、电路板和陶瓷废料。鉴定后走固体分选路线，回收颗粒，由设备配置对应的分选槽。 |
| `liquid_separation` | 密封液样和工艺残料。鉴定后把选中组分送往液样分离路线，出料按目标单质形态选收集槽。 |
| `gas_separation` | 废弃气瓶、混合气样。鉴定 → 气体分离 → 匹配的采样气瓶或钢瓶。 |
| `contract_delivery` | 在研究委托中交付或领取封装标本并登记图鉴，按委托 ID 一次性结算。 |
| `archive_entry` | 研究报告写入图鉴，以记录作为解锁凭据。 |

样品族键与内容对应为 `scrap_metal` 金属边角料、`slag` 矿渣、`circuit_scrap` 电路板、`process_residue` 工艺残料、`sealed_liquid` 密封液样、`waste_gas` 废弃气瓶、`battery_scrap` 电池废料、`alloy_scrap` 合金废件、`ceramic_scrap` 陶瓷废料、`magnet_scrap` 磁体废料、`catalyst_scrap` 废催化部件、`research_contract` 研究委托和 `research_archive` 研究档案。

### 产量、质量和库存

- **首版继承现有回收比例。** 样品每份按 100 个游戏含量单位记账，选中成分凑够 50 个单位产出 1 份，单份耗料为 `ceil(50 / 成分百分数)`。批处理和工业运行重复同一份配方。Fe 占 72% 的批次用 1 件样品，Au 占 10% 的批次用 5 件。同一批投料只结算选中的组分一次。
- **元素库存使用统一整数质量单位。** 每个元素库存单位记为 1 g，元素堆叠、分析天平和游戏称重标签都使用该整数质量。周期表的相对原子质量仍用于科学资料与化学式计算，不再决定元素物品的库存单位质量。样品报告按成分百分比估算克数并取整；样品回收配方仍按现有整数份数结算。
- **仪器与瓶装库存使用整数份数。** 移液管、滴定管的取样量、瓶内含量和容量均为整数容器单位；每单位显示为 25 mL。转移量是请求量、来源余量和接收瓶剩余容量中的最小值，所以容量为 5、已有 4 的瓶子最多再接收 1 单位。小、中、大瓶的现有容量为 4、8、16 单位；旧存档中的瓶子尺寸和数量沿用既有保存方式。
- **非元素物品沿用各自质量来源。** 样品保留数据表中的整数实测克数，固体化合物按式量取整，工具和设备使用整数固定质量；液体密度和气体式量只用于换算单个整数容器单位的质量。
- **设备开工前检查所有占用。** 校验批次已鉴定、玩家阶段、目标路线、耗材、封装容器与产物位。结算时一起扣料、写入产物与进度。输出满则待取，重开面板和读档不能再次结算。

### 外观与玩家可见信息

- **固态单质。** 金属用硬边粉末像素堆，碳、硫、硅、碘等用颗粒或碎晶区分。常规图标透明底，元素符号由 UI 角标绘制。需要封装的粉末或颗粒使用相应封装外观。
- **液态单质。** 溴用红棕液层，汞用银灰高光液层。按瓶型读取遮罩，液面比例由实装容器单位除以容量得到，保留现有液面动画。
- **气态及研究条目。** 气体用气瓶和装量标记。委托标本用密封样本盒，研究档案用记录卡。超重元素缺少可用实测常温相态时用档案图标。Og 的常温固态研究结论在表中标为预测。20 °C 的镓仍沿用固态外观。
- **图鉴和机器显示。** 图鉴给出常温相态、典型来源、解锁条件和交易规则。样品报告给出含量、回收设备和当前可产出的份数。机器只显示当前投料可选的目标。先发现该元素所在批次，再允许图鉴跳转到已解锁的来源或设备。

| 示例 | 阶段与获取 | 展示与交易 |
| --- | --- | --- |
| Fe 铁 | 前期，金属废料 → 提炼反应台 | 金属粉末，12 信用点/件 |
| H 氢 | 前期，废弃气瓶 → 气体分离 | 气瓶，3 信用点/件 |
| Br 溴 | 中期，工艺残料 → 液样分离 | 红棕色瓶装液体，30 信用点/件 |
| Au 金 | 后期，电路板 → 金属回收线 | 金色粉末，220 信用点/件 |
| U 铀 | 研究委托 | 封装标本，委托奖励 |
| Og 鿫 | 研究档案 | 记录卡，固态为预测值 |

## 接入顺序与验收

1. 用符号加载并校验玩法表。先接入图鉴和提示框，并让所有元素保留原有存档 ID。既有库存允许读取与取回。若旧库存中的研究类元素仍是配方材料，保留使用入口直到替代配方随版本上线。
2. 给 81 种常规元素接通可重复获取的样品批次与设备路线，并覆盖当前所有以单质为输入的配方。缺少阶段内可得投入品的配方，在切换掉落前补齐路线或调整解锁点。用表内来源替换通用的「垃圾场找到元素样品」提示，同时取消单质掉落组。
3. 接入委托与档案解锁；把研究条目和可交易物品分别计入游戏的收藏进度与经济结算。确认委托奖励、档案登记与旧库存读取各自只结算一次。
4. 验收 118 行唯一、1–118 连续、类别和 ID 与目录匹配、81 种常规元素有可走通的路线、两种常温液态单质的液面和占格正确、旧存档的物品及瓶子数量可取回。对同一设备路线核对手工、批量、工业的材料与份数，并测试满槽、途中重开面板和读档。
