# 仓库检索（InventorySearch）

给店里所有存货加一个搜索窗口。后期几百件东西塞满仓库、柜台和展示柜时，不用再一个个窗口翻。

对应游戏 0.46D（100-Rev13）。

## 干什么的

- **F3 打开 / 关闭**（可在「模组设置 → 仓库检索」里改成 F4 / F6 / F7 / F10 / None，默认 F3 不占用游戏原版按键）。
- 窗口里是搜索框 + 范围 / 排序 / 只看违禁三个筛选 + 结果列表。
- 搜索按**名称、标识、所在位置**匹配，不区分大小写；空格分开多个关键词时要求全部命中。
- 范围下拉框按容器分：仓库、前柜、后柜、展示柜、暗格、文件柜、垃圾桶、夜间背包、雇员背包、夜市摊位、售货机、饮料机。
- 排序支持名称、价值、数量、位置；「只看违禁 / 赃物」只留下 `ContrabandHelper.IsContraband` 或 `StolenHelper.IsStolenItem` 认定的东西。
- **点一条结果会定位**：找到那件物品所在的容器窗口，窗口没开会先打开（商店里的柜台窗口只重新激活，不改变原来的层级），然后把它占的格子蓝闪 3.5 秒。
- 窗口里的「归类」按钮打开**跨容器归类**：先预览每类会挪多少件，确认后按类别把本店货物挪到暗格 / 展示柜 / 前柜 / 后柜 / 仓库，支持撤销。规则见下面「归类整理」。
- 容器里的容器也能找：背包里的盒子、柜台上的机器内部、货架上的收纳盒，结果里会显示「前柜 › 榨汁机」这样的路径；点进去会打开最里面那个容器的窗口。
- 定位到的是机器内部、盒子内部这种窗口时，会像通知聚焦一样把窗口 `Show()` 出来并居中；柜台窗口保持原来的位置。
- 有一条「定位后收起检索窗口」的开关，默认关；开着的时候点结果会立刻关窗口，免得挡住高亮。
- 窗口可以拖动，位置会记在这次游戏里；右上角 × 或 Esc 关闭。
- F9 开发面板 → Modding → 「仓库检索」也能开关，调试或者没改键的时候用；旁边的「仓库检索：扫描统计」会把每个容器扫到多少件写进日志（F8 看），排查“某件东西怎么搜不到”时先跑一下。
- 离开店铺去淘荒、夜市等其他场景时，检索仍然能查，但**定位店内容器会提示回店里再试**，不会把柜台窗口错误地激活到别的场景。

## 归类整理

搜索窗口顶部「归类」按钮打开（F9 → Modding →「归类整理」也有入口）。

- **先预览再执行**：窗口里按当前范围统计每个类别会挪多少件，确认前不动任何东西。
- **范围**：
  - 「只整理仓库（新货入柜）」：只把仓库里的货按规则往外挪，前柜/后柜/展示柜/暗格现有的摆放不动（默认）。
  - 「整理全部容器」：仓库、前柜、后柜、展示柜、暗格一起按规则重排。
- **规则**：
  - 违禁 / 赃物 → 暗格
  - 武器 / 弹药 / 护甲 → 展示柜
  - 奢侈品 → 展示柜
  - 食物 / 饮料 / 药品 → 前柜
  - 家居 / 彩票 → 前柜
  - 材料 / 工具 / 零件 / 种子 → 后柜
  - 文件 / 其他 → 仓库
- **不动的**：机器、模块、节点、背包/盒子/容器、已固定（P）、碎片、非本店所有、锁住或拿不起来的，以及目标柜子放不下的。整叠东西不会拆开塞，整叠放不下就整叠留在原地。
- **执行后可以撤销**：撤销的是这一轮挪过的物品，尽量放回原位；中途被卖掉/拿走的会跳过并计数。
- 小柜子会先腾空（暗格、展示柜里不合规的先挪出来），再往里放新东西，避免被自己的占位卡死。

## 实现说明

- 扫描范围不是写死某几个格子，而是从 `EmporiumEntry` 的顶层容器（仓库、前后柜、展示柜、暗格、文件柜、夜间背包、雇员背包、夜市、售货机、饮料机、垃圾桶）出发，用 `GraphUtils.FindAllChildrenType<GameItem>` 把子树走一遍。机器内部、背包里的盒子这些都在子树里，所以能一起找到。
- 结果里存的是真实 `GameItem` 引用，不是拷贝；点击时重新读 `parentInventory`，物品被挪走了会提示刷新。
- 定位窗口的顺序：物品的直接容器就是顶层容器 → 用顶层窗口；否则往上找最近的带 `contentWindow` / `examineWindow` 的容器物品 → 打开那个窗口。
- 高亮用 `GameInventory.HighlightSlot` + `SlotMarker`，和游戏拖动时的高亮是同一套；清除高亮前会看 `UIDragHandler.isDraggingAnyUI`，玩家正在拖东西时不抢。
- 归类用 `TryFindOneValidInventorySlot` 找目标格、`SlotMarker.TryAcceptOnce` 整件搬；搬之前检查目标格能放下整叠，**不拆堆、不合并到已有堆**，所以撤销能按物品身份放回去。
- 撤销记录只保存这一轮成功的移动；读档/新档时清空，避免拿旧存档的物品引用去操作新存档。
- 窗口走游戏自带的 `CustomUIManager` / `CustomUIBuilder`，外观和模组设置、调试面板一致；没有自己建 Canvas。
- 快捷键只在没有输入框聚焦、也没在改键时响应（`StoreUIManager.IsTextFieldFocused()` / `KeyBindHelper.IsCapturing`）。

## 已知限制

- 只扫店铺自己的顶层容器；`soldElement`、顾客身上、临时弹窗里的东西不算。
- 容器套得太深、中间某一层没有窗口时，会打开最近一层能打开的窗口，但高亮的那一格可能不在可见的子窗口里；结果里会显示完整路径。
- 每次打开/刷新才重新扫描；物品挪动后点「刷新」，或者重新敲一下搜索框。
- 结果最多显示 150 条，超出的会提示缩小关键词。
- 归类规则目前写死在 `ClassifyService.cs` 里，没有做游戏内规则编辑器；要改“哪类去哪柜”直接改那几个 `TargetOf` / `GroupOf` 分支即可。
- 归类只处理顶层容器里的物品，不会钻进机器、背包和盒子里把东西掏出来；这些容器本身也不会被挪动。

## 编译

根目录的 `Directory.Build.props` 里配游戏路径，然后：

```
dotnet build InventorySearch/InventorySearch.csproj -c Release
```

编完自动拷到 `Mods\InventorySearch\`（dll + manifest + 语言表）。进游戏 → 模组菜单启用 → 重启。

## 备注

- 清单的 `<Capabilities>` 是空的，不读写文件、不联网。
- 配置项存在游戏自己的 `ModConfigs\inventory_search.json` 里，和别的模组一样。
