# 对象获取器（ObjectGrabber）

F9 调试面板里的对象拾取工具：点一下按钮，屏幕上出现一个浮球；把浮球拖到物品、机器、角色或界面上，右侧会实时显示鼠标下面那个对象的详细信息。

对应游戏 0.46D（100-Rev13）。

## 怎么用

1. 游戏根目录有 `dev.txt`，按 F9 打开调试面板。
2. 在 `Special / 特殊` 栏点 `对象获取器`，屏幕右侧出现浮球。
3. 按住左键拖动浮球，浮球下面是什么就显示什么。
4. 右键浮球关闭；也可以再点一次 F9 里的按钮，或按 `Esc`。

## 显示什么

- 物品 / 角色：显示名称、物品 ID、唯一 ID、内部名、数量、单价、物品类型、描述、精灵路径；角色额外显示生命、士气、反应和存活状态。
- 机器 / 窗口：显示窗口标题、窗口尺寸、所在窗口。
- 界面控件：显示对象名、层级路径、实例 ID、激活状态、图层、标签、场景、文本内容、图片、按钮状态和常用组件。
- 场景对象：显示对象名、层级、位置、碰撞体、精灵、排序层和常用组件。
- 所有结果都会带上渲染对象的层级路径、实例 ID 和 UI 位置。

## 怎么找对象的

1. 先用游戏自己的 `RenderHandler.RaycastElement<PixelElement>` 拾取像素元素（物品、机器、角色、窗口都在这套系统里）。
2. 没有像素元素时，用 `EventSystem.RaycastAll` 看最上层的普通 UI；按钮、输入框、滚动区、TMP 文本会被当成有效 UI。
3. 再没有就 `Physics2D.OverlapPointAll` 找 2D 场景碰撞体，按 `SpriteRenderer.sortingOrder` 取最上面的。
4. 浮球自己的 UI 会从射线结果里排除，所以浮球盖住的元素也能读到。

## 实现说明

- 不用 Harmony，不 patch 游戏方法；只读对象信息，不修改游戏状态。
- 不读写文件、不联网，`manifest.xml` 的 `<Capabilities>` 为空。
- 不靠反射列字段：只读取已知类型的公开字段/属性，避免引入 `reflection-external` 能力。
- 中文字体从 `FontLoader` 取，没有时按名称/字形兜底；界面文字不会变成方块。

## 编译

根目录的 `Directory.Build.props` 里配游戏路径，然后：

```
dotnet build ObjectGrabber/ObjectGrabber.csproj -c Release
```

编完自动拷到 `Mods\ObjectGrabber\`（dll + manifest）。进游戏 → 模组菜单启用 → 重启。

## 已知限制

- 普通 UI 的“组件”是常用类型清单，不是完整反射列表；游戏自定义组件如果没有单独适配，会显示为“游戏元素”。
- 浮球优先读游戏内的像素元素；如果它恰好盖在 F9 调试面板上，可能读到面板后面的游戏对象。把浮球移出面板区域即可。
- 只适配当前游戏版本；游戏改动物品/角色字段后可能需要跟着改。
